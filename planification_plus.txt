Pour calculer **la distance totale parcourue**, on additionne simplement les distances de chaque segment du trajet.

### 1️⃣ Trajet donné

Tu fais le trajet :

* A → B
* B → C
* C → A

Donc **3 segments**.

### 2️⃣ Distances connues

On connaît :

* distance **AB**
* distance **AC**
* distance **BC**

### 3️⃣ Distance totale

La distance totale du trajet est :

[
Distance\ totale = AB + BC + CA
]

⚠️ **CA = AC** (même distance).

Donc :

[
Distance\ totale = AB + BC + AC
]

### 4️⃣ Exemple

Si :

* AB = 10 km
* BC = 15 km
* AC = 20 km

Alors :

[
Distance\ totale = 10 + 15 + 20
]

[
Distance\ totale = 45 \text{ km}
]

### 5️⃣ La vitesse (km/h)

La **vitesse ne sert pas à calculer la distance**, mais à calculer **le temps du trajet**.

Formule :

[
Temps = \frac{Distance}{Vitesse}
]

Exemple :

* Distance = 45 km
* Vitesse = 60 km/h

[
Temps = \frac{45}{60} = 0.75\ h
]

[
0.75\ h = 45\ minutes
]

✅ **Résumé**

* Distance totale = **AB + BC + AC**
* Temps total = **Distance totale / vitesse**

On procède en **3 étapes : distance → temps → heure d’arrivée**.

---

# 1️⃣ Calculer le temps pour chaque segment

Formule :

[
Temps = \frac{Distance}{Vitesse}
]

avec :

* distance en **km**
* vitesse en **km/h**
* résultat en **heures**

---

# 2️⃣ Exemple concret

Distances :

* **AB = 10 km**
* **BC = 15 km**
* **CA = 20 km**

Vitesse moyenne :

* **60 km/h**

Heure de départ :

* **10:00**

---

# 3️⃣ Calcul des temps de trajet

### A → B

[
Temps_{AB} = \frac{10}{60} = 0.166h
]

0.166 h = **10 minutes**

Heure arrivée B :

10:00 + 10 min = **10:10**

---

### B → C

[
Temps_{BC} = \frac{15}{60} = 0.25h
]

0.25 h = **15 minutes**

Heure arrivée C :

10:10 + 15 min = **10:25**

---

### C → A

[
Temps_{CA} = \frac{20}{60} = 0.333h
]

0.333 h = **20 minutes**

Heure arrivée finale A :

10:25 + 20 min = **10:45**

---

# 4️⃣ Résultat final

| Trajet   | Distance | Temps  | Heure arrivée |
| -------- | -------- | ------ | ------------- |
| Départ A | —        | —      | **10:00**     |
| A → B    | 10 km    | 10 min | **10:10**     |
| B → C    | 15 km    | 15 min | **10:25**     |
| C → A    | 20 km    | 20 min | **10:45**     |

---

✅ **Heure de retour finale : 10:45**

---

# 5️⃣ Formule générale

Si :

* (H_d) = heure départ
* (d) = distance
* (v) = vitesse

Alors :

[
Heure_arrivée = Heure_départ + \frac{distance}{vitesse}
]
