# 🟢 3️⃣ LOGIQUE MÉTIER – RÈGLES À IMPLÉMENTER

---

# Étape 1 : Récupérer les réservations du jour

Dans `PlanificationService` :

```java
List<Reservation> reservations = 
    reservationRepository.findByDate(date);
```

⚠ Trier par :

* date_heure_arrivee ASC
* nbr_pers DESC (important si manque de véhicule)

---

# Étape 2 : Grouper les réservations par vol

Règle :

> Même vol = même date + même heure d’arrivée
> → même voiture si possible 
> les personnes d'une reservation sont inseparable (ex : C001 -> 5 pers , donc ces 5 sont tjrs assigne ensemble)
Implémentation :

```java
Map<LocalDateTime, List<Reservation>> grouped =
    reservations.stream()
    .collect(Collectors.groupingBy(Reservation::getDateHeureArrivee));
```

---

# Étape 3 : Pour chaque groupe (vol)

### Calcul :

```java
int totalPersonnes = somme(nbr_pers);
```

---

# Étape 4 : Trouver véhicule idéal

Règle :

1️⃣ Capacité ≥ totalPersonnes
2️⃣ Capacité la plus proche
3️⃣ Si égalité → Diesel prioritaire
4️⃣ Sinon → Random

Implémentation :

```java
List<Vehicule> disponibles = vehiculeRepository.findAll();
```

Filtrer :

```java
vehicule.nbr_places >= totalPersonnes
```

Trier par :

* nbr_places ASC
* type_carburant = 'D' prioritaire

---

# Étape 5 : Si aucun véhicule suffisant

Règle :

> Si pas assez de véhicule →
> Les groupes avec plus grand nombre passent en premier.

Donc :

Avant boucle principale :

```java
groupes triés par totalPersonnes DESC
```

---

# 🔴 IMPORTANT – CONTRAINTES À GÉRER

### ❌ Ne pas réassigner une réservation déjà assignée

```java
if(assignationRepository.existsByReservationId(resa.getId()))
    continue;
```

---

### ❌ Un véhicule ne peut pas être utilisé 2 fois le même jour

Il faut maintenir :

